# Phase I Plan — Source Discovery and Corpus Verification

## Research order

1. Inventory official manual editions and relevant Protoss passages.
2. Identify original `StarCraft` and `Brood War` dialogue recordings and subtitles with exact locators.
3. Examine `StarCraft II` campaigns, unit voice lines and editor Conversations data for paired utterances/translations.
4. Reconcile secondary-source transcriptions with original audio.
5. Build phonetic observations without prematurely standardizing a phoneme inventory.
6. Register grammar hypotheses only when attested evidence supports comparisons.
7. Publish coverage, discrepancies, missing sources and phase-exit recommendations.

## Research questions

- NK-RQ-001: Can `En Taro` be segmented?
- NK-RQ-002: Are recurring `na`, `en`, `ik`, `de` grammatical particles?
- NK-RQ-003: Is word order demonstrable?
- NK-RQ-004: Is there corroborated factional variation?
- NK-RQ-005: Which sound contrasts are recoverable?
- NK-RQ-006: What connects speech and the written glyphs?
- NK-RQ-007: Which earlier fan proposals conflict with canonical evidence?

## Exit criteria

- Each attestation has a stable ID and source record.
- All claimed meanings have a specific source or are marked unresolved.
- Source spelling, transcription and interpretation remain separate.
- Contradictions and absent evidence are documented.
- Corpus passes automated structural/reference validation.
- A reproducible Phase I report is available.

## Current status

Repository foundation and unverified discovery seeds established. Primary asset-level verification and phonetic analysis remain pending.
