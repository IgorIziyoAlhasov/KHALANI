# KHALANI — Alys'aril of Protoss Language Research

**Alys'aril** — our chosen name for this project's research sanctuary. The term's precise canonical attestation and translation remain subject to the same source-verification process as every other Protoss expression.

**KHALANI** is an independent, fan-led philological research project documenting Protoss language material from Blizzard Entertainment's *StarCraft* universe, and a carefully labeled effort to develop a speakable **Neo-Khalani**.

> Canon is evidence. Reconstruction is hypothesis. Neo-Khalani is invention constrained by evidence.

## Mission

1. Build a source-linked corpus of attested Protoss expressions, terminology, writing and audio.
2. Distinguish authoritative evidence, secondary transcription, competing interpretation and original invention.
3. Analyze phonology, morphology, syntax and semantics without assuming an unattested grammar.
4. Eventually elaborate a coherent, teachable Neo-Khalani language.

## Status

**Phase I — Source Discovery and Corpus Verification (in progress).** The current seed records are *discovery leads*, **not** verified canon entries. No productive grammar is adopted.

## Contribution rule

Never label a fan reconstruction as Blizzard canon. Cite the source location of every factual assertion; distinguish source spelling from listener transcription and translation from grammatical analysis. Prefer links, timestamps and metadata over redistribution of copyrighted audio or assets.
